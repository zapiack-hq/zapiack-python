# Changelog

All notable changes to zapiack (Python) are listed here. Versions follow [semantic versioning](https://semver.org).

## 0.1.0

First release.

Retries safely, adds an idempotency key to every send, raises errors with stable codes, pages through lists and verifies webhook signatures.
Covers email (sending, contacts, segments, templates, domains, broadcasts), SMS and push (messages, segments, images, results and webhooks).
